# Split-feature LegalIR: remaining gaps and next experiments

The completed split-feature run improves exposed authored joint exact outputs to 32/72, but legacy retention falls to 94/96. No checkpoint is selected or promoted. The next work should address the observed failures before expanding training scale.

1. **Restore temporal retention.** The two legacy regressions are missing temporal spans on `native-tuning-calendula-t6-q7-o` and `native-tuning-calendula-t6-q7-p`. First diagnose their saved presence scores and temporal boundaries against the retained parent. A finite saved-score experiment can test parent temporal-presence routing while keeping learned span boundaries, without claiming another trained model. A subsequent predeclared training comparison can test replay/distillation on the original training rows and parent source-only predictions. Keep exposed evaluation references outside the training child. Require legacy 96/96 and zero permission regressions before promotion; report new-panel changes on the same IDs and include abstentions.

2. **Improve span binding.** `actor_duration_name` remains joint exact 0/12 on development and 2/12 on evaluation; evaluation object spans match 45/72. Add contrastive training examples that distinguish names, object titles, duration-bearing conditions, exceptions, and actual temporal deadlines. Specify source/target provenance and deduplicate by provision and template group. Use development failures to design training changes and obtain a fresh held-out test set before claiming generalization. Record actor, object, temporal presence, boundary, and full-rule errors separately.

3. **Repair modality through reviewed legal context.** Freezing the parent retains all 392 modality vectors, including 10 incorrect choices among the newer 24 authored permission rows (14 P, 4 O, 6 F). A context-sensitive modality branch needs independently reviewed examples of permission, obligation, prohibition, scope, negation, exceptions, definitions, and cross references. Any adapters or routing must demonstrate legacy retention and calibrated abstention. Restoring labels by copying exposed references is not a fidelity result.

4. **Establish real US Code fidelity.** The eight current law-source rows have no reviewed targets and remain unscored. Use the identified `justicedao/open-us-law-span-cache` and `justicedao/uscode-autoformal-span-cache` as source/provenance resources; their presence does not make derived labels independently reviewed gold. Freeze dataset revisions, source spans, provision context, reference links, and reviewers' adjudication before evaluation. Split by provision and near-duplicate/template groups. Measure legally material errors, including missing exceptions, shifted quantifier scope, misplaced negation, temporal triggers, actors, and imported definitions. Publish coverage and unresolved disagreement as well as accuracy.

5. **Qualify genuine 8D, 384D, and 768D conditioning.** This run configures 384 but disables latent use and makes zero external encoder calls. Preserve the trained source-only baseline. For each real encoder/checkpoint pair, establish exact input/output dimensions, revision and tokenizer identity, normalization, training objective, and decoder compatibility. Predeclare matched source-only, true-latent, zeroed, shuffled, and dimension-matched controls under comparable compute. Measure whether latent input improves independently held-out fidelity and whether unsupported input is rejected. Dormant placeholder controls cannot establish latent semantics.

Report build success separately from source fidelity, proof relevance, and forbidden placeholder usage. No such build or broader-family qualification has been performed in this run.

Contribute source, tests, result summaries, and finite public receipts through isolated source/root branches; retain other agents' newer main changes, worktrees, recovery refs, and canonical indexes.

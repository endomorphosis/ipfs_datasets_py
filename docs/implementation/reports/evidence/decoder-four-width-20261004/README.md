# Four-width training comparison

See [the training guide](../../../../autoencoders/four_width_training.md) and [results.json](results.json) for the measured outcomes and limitations.

Six formula-sidecar fits cover 8D, 384D and 768D. The 4096D native-input gate remains closed. No production promotion or Lean admission occurred.

Concatenate the numbered archive parts in order, verify the combined SHA256 in manifest.json, then read the gzip tar archive. It contains states, predictions, training reports, frozen new runners, resource receipts and audits. Prior frozen runtime and input dependencies are bound through the linked prior-evidence manifest chain. Local model assets and the large external 4096D diagnostic vector files are not bundled.

# Content-matched Legal decoder comparison

Four controlled 384D fits compare independent sampling with content-matched
sampling at exactly equal per-source exposure. The candidate remains optional:
fresh final exact reconstruction ties at 63/96 endpoint observations, while
original development exact reconstruction regresses from 96/96 to 93/96.
The unchanged gate retains both candidate initial states. No checkpoint is
promoted; no Lake admission or federal-law formalization is claimed.

- [Method and interpretation](../../../../autoencoders/content_matched_training.md)
- [Results](results.json): both seeds, selected/final endpoints, per-family and
  per-field metrics, timings, error examples and resource scope.
- [Manifest](manifest.json): archive-part and member hashes, original artifact
  paths, prior published evidence, source pins and test coverage.

The split XZ archive contains the completed run, both retained failed setup
attempts, frozen source/test files, trained numerical states, all control panels,
source-only prediction barriers, fresh references and native embedding receipts,
independent audit, documentation review and publication compatibility receipts.
Verified local encoder model assets are referenced by hash and are not included.
Unchanged external dependencies are bound through the prior published evidence.
Numerical state exports omit optimizer state and are not resumable training jobs.

Reassemble and inspect locally:

```bash
cat evidence.tar.xz.part-* > evidence.tar.xz
sha256sum evidence.tar.xz
# Compare against manifest.json before extracting.
tar -tJf evidence.tar.xz
```

Only the 384D authored Legal formula sidecar was trained in this comparison.
The 8D linguistic teacher is preserved and 768D was not trained. Vocabulary and
context limits remain fixed. Bridge names are empty; these timings are not a
bridge-on legal-IR speed measurement. The Constitution remains unformalized.

# Decoder continuation and native4096 readiness

See [the training guide](../../../../autoencoders/four_width_training.md) and [results.json](results.json). Six saved-state continuations cover 8D/384D/768D, and a separate 8D object-projection pair is retained. These are formula decoder sidecars with frozen source encoders. Native4096 work validates a compiled vocabulary/tokenization path; it does not execute an embedding forward or train a 4096D decoder.

All cohorts are authored development or previously exposed regression data. No Lake admission, qualification, promotion or global-convergence claim is made. Historical 8D linguistic teacher weights are unchanged.

Concatenate the numbered archive parts, verify the combined SHA256 in manifest.json and read the gzip tar. Every archived member was read back and hashed. Successful runs, failed attempts, source snapshots, predictions, private decoder states, audits and resource receipts are retained. External pretrained weights are excluded; historical inputs/runtime dependencies remain bound through the prior published evidence chain.

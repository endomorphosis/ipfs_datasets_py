# Generated-replay consistency experiment

This evidence compares three fresh training trajectories for the 8D, 384D and 768D experimental formula sidecars: the previously published head-LR10 baseline, zero-weight joint replay, and the same joint replay with generated-field supervision at weight 0.05. Each width uses two fixed seeds. The training/development corpus and acceptance rules are unchanged.

Read `results.json` for the complete plan, per-run selected and final outcomes, resource receipt and test results. The usage guide is `docs/autoencoders/generated_replay_training.md`. All 18 fits, 54 model states, 324 evaluation panels, auxiliary receipts, source files, diagnosis, tests and independent arithmetic review are retained in the archive. Superseded preflight and audit attempts remain labeled separately.

The 8D sidecar here uses linguistic-feature hashes; it is not the historical linguistic teacher. The larger models use authenticated cached semantic embeddings. This is an authored Legal development corpus already exposed by previous experiments, not fresh federal-law holdout evidence. No original teacher or protected checkpoint was rewritten.

These results do not establish Lake admission, formalization, source-semantic qualification, convergence, native validation or production promotion. No `lake build` ran in this study. Numerical reconstruction and syntax are separate observations. The Constitution remains unformalized.

## Reading and reproducing the evidence

`manifest.json` lists the SHA-256 and byte size of every archive part and every member. Verify the ordered parts, concatenate them as `evidence.tar.xz`, and verify the logical archive before extraction. Parts are at most 48,000,000 bytes. The manifest maps original absolute artifact paths to archive members and authenticates references to earlier evidence using pinned Git commits and archive hashes. It also lists the local embedding/runtime assets that remain external.

`source/` contains exact experiment producers and tests. `validation/` contains the sealed plan, manifest, all training/results files, source-provenance receipts, diagnosis, independent numerical audit and resource monitoring. `validation/preflight-r1/` is the superseded successful regression freeze before the final benchmark fail-fast checks; its old paths are historical, not current imports.

The retained freeze, test, guardian, audit and packaging scripts document the workflow. Reproduction requires resolving the manifest's original paths to current extracted members and predecessor references, and providing the authenticated local assets. No automatic downloads are performed. The resource guardian is specific to the existing local scheduler contract and uses read-only observations of its own lease; it must not recreate another machine's shared state from an evidence snapshot.

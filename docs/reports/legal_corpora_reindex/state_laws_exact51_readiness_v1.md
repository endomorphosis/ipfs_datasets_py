## Publication invariant

A jurisdiction counts as ready only when all of the following are true for the
same source observation:

1. the official source-derived root and every reachable hierarchy/leaf member
   are enumerated;
2. every discovered source member has an exact fetched, excluded, duplicate,
   quarantined, or failed-final disposition, and the algebra closes;
3. parser inputs and transport receipts are retained with URL/content identity;
4. a second parse uses retained inputs only (zero network) and reproduces the
   first frontier digest and ordered canonical output keys;
5. the canonical `STATE-XX.jsonld` and normalized completion receipt agree;
6. the statutory-text rights basis is `public_law_no_state_copyright`.

The rights gate admits enacted public-law text under the government-edicts
doctrine. It separately excludes editorial annotations, database selection or
arrangement, and site presentation; those exclusions do not imply copyright in
the public laws themselves.

Partial checkpoints, sample/cohort receipts, static seed lists, and a successful
parser unit test do not satisfy this invariant.

## Acquisition reuse and WARC request policy

- Every retry reopens the jurisdiction acquisition ledger and keys reuse by the
  exact official URL plus sanitized request identity; a retained parser input is
  replayed without network access.
- Plural retained replay builds one immutable request-identity index and resolves
  an ordered request wave in `O(ledger + requests)` time; it fails closed on
  ambiguous identities or changed content instead of rescanning the full ledger
  once per page.
- Hierarchy and leaf URLs are submitted as plural same-domain waves. Common
  Crawl recovery uses grouped WARC range requests, and retry waves contain only
  unresolved residual URLs. Per-page archive loops are forbidden.
- Static lists may support diagnostics, but strict acquisition and certification
  use only source-derived current membership.
- Existing canonical artifacts, checkpoints, and retained evidence are never
  overwritten or treated as complete merely because a later run can open them.

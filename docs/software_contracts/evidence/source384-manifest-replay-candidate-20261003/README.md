# Manifest replay: local candidate qualification

This package qualifies the current on-disk manifest replay, private graph compaction, and source-report lifetime changes for a local candidate commit. It does **not** qualify a new Docker run, full supervisor completion, benchmark reward, token saving, proof, or admission-window memory improvement.

The candidate freshly reads bounded CAS bytes on every replay. An exact raw-byte key and fresh CID digest can reuse a previously validated private manifest only while the native reader, JSON dependencies, producers, registration, and configuration remain unchanged. Public CAS reads and unknown/custom readers retain full parsing and validation. Early cache-owned anchors prevent a custom reader installed before the manifest module imports from being silently adopted. Compaction shares exact immutable metadata within the private graph; returned records remain detached. Source/head/SQL/AST and model checks, native scheduling, and deadlines remain in place.

`qualification.json` records 273 distinct passing controls: 266 passed in the broad actual-source run, and the seven Source384 cases passed in an explicitly configured-client retry. The real cached checkpoint test loads one model, emits four unverified candidates and one token-deferred unit, publishes through the native registry, and verifies warm/cold replay without another numerical worker. Source and authority changes are rejected. There are no skipped tests, provider calls, training steps, or semantic/proof authority upgrades.

Two unsuccessful generations remain visible:

- `controls-01`: two collection errors, before any tests ran. Two authored tests used bare sibling fixture imports, which the earlier off-tree runner made available. Only those imports were changed to the package-qualified test path for the repository's native importlib collection mode.
- `controls-02`: 266 passed and seven fixture errors. The host-default client requested 16 CPU slots / 99,688 MiB while an active foreign daemon occupied the same native ledger with a 4-slot / 9,830-MiB profile. The existing configuration fence refused the mismatch. This is retained as a host-default startup refusal.
- `controls-03`: the seven Source384 cases passed in 8.83 seconds using the exact stored profile through `get_global_resource_scheduler(existing_config)`. An external test plugin selected this canonical facade only at `codebase_resources.get_global_resource_scheduler`. It used the same locked ledger, native sampler, thresholds, capacity, and headroom; no ledger replacement, daemon changes, resets, or timeout changes occurred. The earlier foreign lease had naturally disappeared by this retry's before-sample. The run therefore does not establish concurrent operation alongside that daemon or qualify host-default startup. The temporary dependency selection was restored afterward.

The [separate three-arm comparison package](../source384-manifest-combined-comparison-20261003/manifest.json) preserves raw source-only measurements and their generations. The combined candidate reduces accounted private memo retention from 89,210,779 to 29,251,864 bytes and removes the sampled warm-load allocation increase. Its second-observation anonymous RSS is higher than baseline, so this is **not a demonstrated admission-memory fix**. Full-pipeline qualification remains required. The source-report lifetime change is not exercised by that source-only comparison.

`final-sources/` and `final-source-pins.json` contain exact current owners and authored tests. `before-test-import-fix/` retains earlier test bytes. `reviews/off-tree-source-review.json` reviews the unchanged runtime candidate and earlier test import generation; the final actual-source tests cover the import correction and added lifetime change. `references/off-tree-qualification.json` is historical provenance, not an additional aggregate test count. Its earlier mismatched-tokenizers failure is described by the adjacent diagnosis receipt.

Command and exit receipts retain original host paths. Relative producer/test keys resolve beneath the datasets checkout; corresponding changed files are copied under `final-sources/`. External artifact paths are provenance pointers, not promised paths inside this package. Only explicitly selected code, tests, commands, bounded logs, XML, and redacted scheduler receipts are included. There are no benchmark task bodies, model weights, database/CAS payloads, credentials, or lease authority keys.

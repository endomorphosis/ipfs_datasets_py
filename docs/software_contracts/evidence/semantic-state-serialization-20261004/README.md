The returned bytes/CIDs and ordering match the historical serializer. Custom records, spans, properties, slot/function replacements and mutable outer representations retain historical dispatch. No serialized body or identity is cached across calls, and catalog validation, AST reconstruction, source/proof fences, admission limits and deadlines are unchanged.

Two before/after pairs used the archived original model via an explicit import hook or the current model; no production file was rewritten. These are small host component observations, not a statistically powered benchmark, full supervisor result, or memory/admission claim.

# Norm term-use and definition-evidence integration

The new `legal_norm_definition_evidence_v1` companion connects exact proposed
term occurrences to separately replayed contextual definition alternatives.
It preserves the existing norm, definition, context, signature and dependency
owners. The [API contract](legal_norm_definition_evidence_v1.md) describes the
original inputs and explicit nomination request.

## Implemented scope

Each association retains the selected typed node, its governing binder,
predicate argument position, modal ancestry and complete inverse source-anchor
mapping. Its contextual nomination must address the exact norm source unit and
support a required scope or contributor subject of the selected definition.
Identical words in another occurrence or edition cannot replace those identities.

The full norm preparation and contextual definition correspondences are
regenerated. Both endpoints must share the same complete context packet,
source population and attachment population. Optional definition assessments
are separately replayed against the same candidate bytes, subject, physical
contexts and dependency manifest, using explicit original trust inputs.
An absent assessment remains absent. A pending assessment remains pending.

Competing definitions and repeated term occurrences remain separate. No alias
formula, predicate substitution or admitted graph edge is produced. The old
subjects and their signatures do not cover the new unsigned companion, and
the original norm preparation still reports that it does not itself consume
typed definition reviews. The companion's distinct status records this new
evidence connection without rewriting historical records.

Original unresolved issues and context obligations persist. Governing use
remains null, all semantic/applicability/admission authority flags remain false,
and training/evaluation masks remain integer zero. Complete inputs are required
again for downstream validation; compact commitments do not replace replay.

## Fictional qualification fixture

The authored fixture has two alternatives for the same definition source:
one opaque whole-body predicate and one structured interpretation. Each is
explicitly nominated for two occurrences of the `actor` variable, making four
links. Each occurrence retains its own formula path and argument context.

The norm's fictional `Clérk` literal and the definition's fictional head differ.
That association is deliberately an authored nomination, not inferred synonymy
or a demonstrated legal equivalence. The interface checks source/syntax custody;
it does not decide whether the association is meaningful. Independent meaning
and applicability review remain necessary even when all transport checks pass.

Both original definition assessments have unavailable trust, empty key and review
populations, and pending status. The retained replay creates no signatures and
uses no production keys. Synthetic signature tests in the existing regression
suites are distinct from the retained example.

## Remaining work

The next source-level milestone is a supported, explicitly supplied relational
interpretation for an actual use provision, followed by independent review of
its meaning and each proposed definition's edition, scope and applicability.
The original §7213/§7214 reports still require their unresolved grammar and
interpretation work; this fictional replay does not qualify those provisions.

Equality/cardinality, counting scope, purpose and anaphora remain grammar gaps.
Review of an association, scoped graph composition, native Lean qualification
and qualified decoder training/holdout evaluation remain separate stages.
No model, training, solver, Lean build, upload or accepted-state publication is
performed by this companion.

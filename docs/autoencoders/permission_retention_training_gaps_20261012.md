# Remaining LegalIR training gaps after the permission-retention comparison

The comparison isolates a useful tradeoff. Updating the full source model reaches 22/72 joint exact outputs on the newer authored panel, but changes three old permissions to obligations. Updating only the six span heads preserves every old output and all 392 modality vectors, but leaves the newer panel at the parent's 6/72. Frozen features protect established behavior and restrict adaptation. Both candidates remain retained; the passing old retention gate alone is not a model selection rule.

1. **Separate modality and span representations.** Start a matched experiment from the same parent with a frozen modality encoder and a distinct trainable span encoder, initially copied from that parent. Train presence/start/end against the trainable branch. First measure a clearly labeled post-hoc saved-score recombination as a diagnostic; it is not a trained model or independent evaluation. Then train the actual separated model with explicit branch provenance and true optimizer membership. Compare against the two retained arms at equal data, order and update budgets. Require exact old raw/joint retention and zero new old permission-to-obligation errors. Frozen modality still preserves its existing errors, so this architecture cannot establish general modality correctness.

2. **Repair modality errors with reviewed context.** The frozen parent is already wrong on ten of the newer panel's 24 permission heads. New legal reference work must establish actors, scope, exceptions, definitions, cross-references and effective dates, not merely match modal words. Retrieve source provisions from the user-provided `justicedao/open-us-law-span-cache` and `justicedao/uscode-autoformal-span-cache` datasets with immutable revision and source-span provenance. Independently review targets and ambiguity/abstention decisions. Do not treat cache outputs as reviewed gold automatically.

3. **Create a fresh statutory evaluation boundary.** All existing authored panels are exposed and share templates. Freeze provision-group and cross-reference-aware splits before training; keep amendments and near duplicates together. Record reviewer agreement, adjudications and unformalizable examples. Report exact structured IR, role and scope errors, permission confusions and abstentions separately. Run more seeds only after the architecture and reference boundary are fixed; a single matched run supports descriptive findings only.

4. **Qualify genuine latent decoders separately.** This experiment uses disabled384 placeholders and makes zero encoder calls. Inventory the already trained 8D, 384D and 768D encoders/decoders across published main, branches and retained worktrees, preserving immutable ancestry and recovery references. For each actual encoder pair, bind preprocessing, latent normalization, dimensionality, checkpoint hashes and training provenance. Compare source-only, true latent, zero, shuffled and mismatched latent controls on the same independent statutory split. Do not infer latent quality from the source-span experiments.

5. **Extend logic-family and compiler coverage.** Enumerate the repository's supported logic families from pinned source. Define typed LegalIR constructs, explicit supported/unsupported mappings and fail-closed adapters for each family. Validate source provenance and complete legal scope in addition to syntactic well-formedness. Run actual `lake build legal` in the qualified Lean environment on generated outputs; separately assess semantic agreement, proof assumptions and any unresolved obligations. Current runs execute no compiler and qualify no new logic family.

6. **Keep storage and publication bounded.** Retain both checkpoints, failures and review history. Use the existing 145 GB reservation cap and a distinct released 200 MB claim for each bounded run; never raise caps or alter other agents' records to make a run fit. Publish immutable additive Hub releases, preserve all previous remote file identities, and verify every new downloaded byte. Keep full shared ledger bodies private. Contribute finite source, tests, recipes, measurements and gaps through isolated Git worktrees, preserving newer main commits and other agents' branch/worktree histories. Recount current storage before any longer training campaign.

The current two runs completed 64 total updates, released both reservations, and froze 87 output files before their new comparison was scored. The all-parameter control reproduces the preceding full-training result. These are engineering findings, not an independently reviewed legal autoformalization benchmark.

# LegalIR execution roadmap refresh — October 16, 2026

This is a planning and metadata-only update to the existing
[LegalIR US Code improvement plan](../../legal_ir_uscode_corpus_improvement_plan_20261015.md).
It reconciles the published source/review, typed-IR, decoder, graph and native
execution findings without creating a competing implementation or task backlog.

## Retained evidence

- `hub-metadata-summary.json` summarizes the two public Hub API observations at
  00:36 UTC and their immutable revisions. The two `*-api.json` files preserve
  the exact response bytes; the two `*-card.md` files preserve pinned cards.
- `parallel-plan-review.json` records the inspected published contributions and
  the separate, unmerged counted-frame prototype. It preserves their individual
  qualification limits rather than treating authored fixtures as legal gold.
- `metadata-independent-review.json` independently recounts the frozen public
  metadata and checks response/card commitments against the saved summary.
- `roadmap-independent-review.json` checks the final plan, local links, retained
  historical qualification body and source/meaning/graph/Lean dependency order.
- `decoder-roadmap-review.json` checks matched experiments, teacher scope,
  compatible warm starts, latent interventions and long-context/output limits.
- `publication-manifest.json` binds the ordinary staged bodies for this update.
  It excludes itself and the final publication commit to avoid a hash cycle.

File descriptors, advertised path sizes and observation rows are not counts of
unique provisions or accepted legal meanings. The unchanged entity payload is
linked to its separately completed full census; it was not downloaded again.

## Scope

No dataset payload, checkpoint or embedding was loaded; no product module was
imported. This update starts no inference, training, review signing, graph
migration, model upload, resource qualification or Lean process. Checks are
static documentation, JSON, exact-byte and Git/link checks. Existing source,
model, review and execution evidence retains its original profile and limits.

The owned planning worktree is isolated from the older, dirty canonical checkout.
Publication to `origin/main` does not refresh that checkout or its runtime.
Private postpublication verification records the resulting remote commit without
adding a self-reference to this evidence generation.

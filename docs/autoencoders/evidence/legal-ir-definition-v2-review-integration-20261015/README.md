# LegalIR V2 context and review evidence

This generation qualifies the existing eight-file V2 context/review contribution
and a retained-source subject replay. The
[integration guide](../../legal_definition_v2_review_integration_20261015.md)
explains what the interfaces establish and the remaining reviewed definition/use
component.

`integration.json` binds original/imported Git bodies, author closeout artifacts,
exact raw execution copies and separately retained complete source inputs.
`qualification-v01` preserves **966 unique cases across 30 modules**, with zero
failures/errors/skips and 22 additional passing subtests. Its 501 listed local
inputs and HEAD/index were unchanged during execution.
`independent_recount.json` recounts those raw results without rerunning tests.
The original author qualification is a subset, not an additional 251 cases to
add to this total.

`real-source-subject-v01` retains exact FOL/TDFOL request/report/candidate bytes,
context packets and expected commitments, preparation/dependency manifests,
required IDs, review subjects and graph bundles. The original HTML, historical
full sampler and newly regenerated full sampler stay external under the paths
and hashes in the integration inventory and probe receipt. Both the six-input
byte hashes and full canonical source commitments remain necessary.

Each family has six physical contexts, 36 open slots, a declared 40-artifact/
39-edge dependency inventory and the same exported candidate graph referenced
by its subject. The replay prepares subjects only: reviews are zero, no
assessment occurs, and no review trust/key/clock input is chosen. A successful
mechanical replay does not establish actual source meaning or training gold.
`independent_probe_review.json` checks retained bytes, references and reported
invariants; it performs no separate product replay or legal review.

The raw launch receipt and streams are in `real-source-subject-v01-launch`.
`probe_launcher.py` pins qualification, current source inputs, itself, the new
probe and the exact reused earlier probe helper before and after execution.
The earlier generation is preserved; no report is relabeled to another producer
or publication commit.

From the repository root, use fresh exclusive directories:

```bash
python docs/autoencoders/evidence/legal-ir-definition-v2-review-integration-20261015/qualification_runner.py /absolute/new-qualification-directory
python docs/autoencoders/evidence/legal-ir-definition-v2-review-integration-20261015/probe_launcher.py --qualification /absolute/new-qualification-directory --output-directory /absolute/new-subject-directory
```

The launcher requires the passing qualification's HEAD, index and file bytes to
still match. Retained source assets must exist and match the independent pins.
Test and probe process groups have enforced 1,200-second and 600-second limits.
Private output/cache paths and stripped ambient application variables are
recorded; offline flags are application settings, not a network sandbox.
The real-source subject replay uses public owners in the same process. The
separate authored graph tests cover a fresh interpreter.

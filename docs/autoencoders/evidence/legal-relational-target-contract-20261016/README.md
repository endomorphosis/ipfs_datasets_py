# Relational decoder target and example evidence

This phase implements the [fixed target and candidate example contracts](../../legal_relational_decoder_target_contract_v1.md)
over the existing relational norm, strict typed codec and original source/typed
join owners. It does not implement the proposed compact AST-action decoder or
train a numerical head. All training/evaluation-gold masks remain zero.

- [Source review](independent-source-review.json): initial frozen product/test
  generation, with codec authorship disclosed and separate adapter/test reviews.
  Its guide hash identifies the earlier prequalification guide version.
- [Administrative controls](administrative-controls-audit.json): 142 cases,
  zero failures/errors/skips; no native grant claimed. The source cohort was
  unchanged before and after.
- [Original driver reuse](qualification-driver-reuse.json): attempt01's worker
  is byte-identical to the retained export qualification worker. Its historical
  receipt schema is retained; selected modules determine this phase's scope.
- [Retry collection profile](collection-profile-v02-review.json) and
  [independent review](independent-collection-profile-v02-review.json): v02 adds
  only `--confcutdir` at the common selected test directory. It preserves the
  SDK/network/process guards, source-buffer loader, fixtures, assertions,
  complete selected files and resource profile.
- [Failed attempt and recovery](qualification01-failure-recovery-audit.json):
  all 142 cases failed ancestor-package setup before calls; the SDK guard
  refused the checkout basename `datasets`. Existing exact-owner recovery
  retained ten files/984,985 bytes and released 134,217,728 bytes of accounting.
  [Recovery reuse review](recovery-script-reuse-review.json) records the six
  literal task/path/request substitutions, with its recovery body unchanged.
- [Independent native audit](native-qualification-independent-audit.json):
  attempt02 passes the same 142-case population, verifies the original native
  closeout and separates the earlier failed operation.

Requests [01](qualification-request-01.json) and
[02](qualification-request-02.json) bind the exact source cohorts and selected
modules. Attempt02 uses 2 GiB RAM, one CPU slot, one child slot, 128 MiB storage
and a 300-second productive bound under the unchanged F07 policy. It declares
255 source pins and verifies 104 executed product source origins. Native ownership is
cooperative process-group/resource accounting, not kernel containment.

Original parent captures, request/source preimages, physical witnesses, JUnit
and complete native artifact bodies remain retained locally. Public audits
are bounded projections with independent hashes; raw operational reservation
and lease identities remain private. The publication subset is not a complete
standalone replay bundle.

No model/vector/corpus payload was opened, no inference or training ran, and no
human meaning review, graph admission, model upload or Lean build occurred.
Codec round-trip and candidate preparation do not establish statutory accuracy
or semantic authority. The [parallel execution design](../../legal_ir_span_graph_lean_execution_plan_20261016.md)
and [corpus roadmap](../../legal_ir_uscode_corpus_improvement_plan_20261015.md)
retain the reviewed-target, graph and Lean milestones.

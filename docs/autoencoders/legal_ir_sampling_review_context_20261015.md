# LegalIR cross-section review evidence qualification

Date: 2026-10-15. This continues the [US Code improvement
plan](legal_ir_uscode_corpus_improvement_plan_20261015.md) and the
[sampled-source section bridge](legal_ir_sampled_primary_bridge_20261015.md).
The review recorder can now accept exact supporting evidence from a separately
pinned source bundle in a distinct contextual-response domain.

## Implemented behavior

Six additive APIs in `legal_source_sampling_review` delegate to the bounded
`legal_source_sampling_review_context` helper. They prepare and replay context
packets, record and validate explicitly supplied declarations, and summarize
the complete review population. The original v1 bundle/response APIs remain
unchanged by default; the shared private declaration validator receives extra
evidence only through the new validated context path.

Each attachment binds the exact target bundle and subject, supporting bundle and
subject, and an unreviewed role label. Every cited supporting evidence envelope
includes both subject identities and the original evidence reference. Another
target's envelope is rejected even when both targets have valid nominations.
An unlinked supporting occurrence's envelope is also rejected. Original shared
full-document views remain available: this is structured citation scoping, not
information isolation of the other passages on that page.

Complete source bundles are replayed and retained once, with all guides and
withheld parents. Canonical-byte validation rejects type substitutions, altered
flags, removed subjects and resealed changes. Original context declarations and
source versions are preserved. Role labels do not establish governing scope.
Separate packet, response and population schemas prevent silent interchange
with v1 responses. No reviewer answer or signature is generated by this API.
See the [usage guide](../guides/legal_source_sampling_review_context_20261015.md).

## Remaining integration work

The cross-bundle response API gap is closed for this qualified profile. The
definition-binding adapter still calls the original v1 population owner; it
needs an explicit supported handoff for contextual responses. Such a handoff
must preserve the complete context commitment and exposure/declaration domain
without converting unsigned declarations into authenticated reviews or gold.

Independent source/meaning decisions and complete typed targets remain absent.
The current unary norm compiler does not encode the full assignment, transfer
and approval semantics in §7213 or the numeric cap, purpose and pronoun structure
in §7214. Extending that grammar and checking meaning preservation remain
prerequisites for supervised LegalIR training and the connected Lean corpus.

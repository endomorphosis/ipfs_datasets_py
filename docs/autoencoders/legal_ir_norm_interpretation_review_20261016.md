# Norm interpretation review handoff qualification

The new fixed-domain norm-review wrapper passes **299 selected tests**, including
54 new review cases. A retained fictional example fully replays its source,
relational correspondence, contextual nomination, review subject and assessment.
With no keys or reviews, its assessment remains pending and its training masks
remain zero. This closes a review-evidence interface gap; it supplies no accepted
statutory meaning or learned checkpoint.

The [API contract](legal_norm_interpretation_review_v1.md) reuses
`legal_graph_review`, Profile G signature verification and the existing dependency
invalidation owner. It introduces a distinct norm subject, claim, action and
audience. Prior graph and definition signatures cannot approve this subject.
No verifier, policy, trust registry, signer or clock default is replaced.

## Implemented and exercised

The wrapper replays the entire source-to-relational correspondence and preserves
its source issues, ordered arguments, modal scope and null governing-definition
use. Optional contextual evidence is replayed through the existing context owner.
The target must match the complete sampling report, descriptor/raw commitments,
sealed unit, occurrence and context references; a similar phrase is insufficient.
All selected target nominations and commitments to the complete context packet
and original sources are retained. Typed definition-review assessments are not
yet consumed by this profile.

Review obligations contain all six original context slots, every original
unresolved issue and seven explicit interpretation questions. The shared
verifier authenticates statements under caller-selected keys and checks the
declared roles, scope, intervals, revocations, dependency observations and exact
evidence bytes. Independent norm-readiness blockers preserve partial/unassessed
source coverage, unresolved meanings and unverified definition applicability.
Authenticated declarations do not clear those blockers or grant admission.

Static audit found two defects before execution and both were corrected:

- Embedding a full preparation in a signed subject exceeded the shared verifier's
  shallower JSON contract for some valid syntax trees. The compact subject now
  commits the complete external preparation with exact hashes. Assessment still
  requires and regenerates it. An 18-NOT-node regression qualifies this path
  without changing the verifier or truncating the formal evidence.
- Producer pins were initially captured after the first correspondence replay.
  They now precede replay, following bounded original-input preflight. A test
  changes a copied context owner's bytes during first use and requires rejection.

The new tests also cover self-rehashed substitutions, missing dependencies,
changed source bytes, wrong editions/targets, distinct signing scopes, expired
or revoked keys, missing evidence, duplicate-principal constraints and mutable
input/producer changes. Cryptographic tests use synthetic credentials. Their
signatures are not production or human reviews.

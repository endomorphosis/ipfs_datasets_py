## Next gap

These owners do not yet connect the unresolved statutory role declarations to a
source-bound relational interpretation. That join needs complete source coverage,
explicit role and modal choices, applicable definition dependencies, retained
alternatives and independent meaning review. Context nominations alone cannot
authorize it. The original review signing domains must stay distinct from any
new interpretation subject.

Equality, cardinality/counting frames, extra semantic sorts, purpose and anaphora
remain unsupported by this relational profile. The shared typed syntax can store
equality, but the selected native Lean route cannot yet lower that node. A cap
such as three distinct recipients therefore needs both explicit counting scope
and an independently qualified lowering extension; embedding the cap in an
opaque predicate name does not implement it.

The [norm gap specification](legal_ir_statutory_norm_profile_gaps_20261015.md)
and [corpus improvement plan](legal_ir_uscode_corpus_improvement_plan_20261015.md)
retain the subsequent review, graph, training and Lean gates. No model fitting,
checkpoint selection, source acquisition, upload or backlog-state promotion is
part of this integration.

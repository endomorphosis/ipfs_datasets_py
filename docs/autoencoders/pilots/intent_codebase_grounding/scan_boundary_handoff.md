## Concrete improvements

The Git context reads one fixed bounded native configuration primitive, `config --null --includes --show-origin --show-scope --list`, before the first source/status query. It preserves the exact ordered output with scopes, origins, duplicates and native HOME/XDG/include resolution. It refuses all `filter.*` declarations, Trace2 configuration, partial-clone/promisor settings and alternate-ref commands. The conservative filter rule includes empty/bare settings and `required=false`. It does not silently normalize conversions or replace cached embeddings.

Normal Git reads compare that configuration witness before and after execution, and context exit checks it again after the final Python/SQL/CAS helper. Environmental trace targets are refused before any native child. Child controls explicitly disable Trace2 destinations, pagers, optional index writes, allowed transport protocols and lazy fetching; status uses `--ignore-submodules=all` to preserve opaque submodule boundaries without native child traversal. Git documents [Trace2 overrides and targets](https://git-scm.com/docs/git-config) and [protocol/lazy-fetch controls](https://git-scm.com/docs/git). Actual pinned-binary tests qualify the inspected controls and refusal behavior in these fixtures; they do not establish arbitrary native/helper/shared-library closure.

A configuration witness is a cooperative observation, not immutable native consumption. A hostile writer can change configuration between preflight and a native read. Git still reads cwd/-C/config/include/index/object/attribute/ignore paths by pathname. Those native consumption races require a separately qualified immutable or isolated execution path before arbitrary repository admission. Root descriptor checks detect persistent replacement before/after calls; they cannot atomically bind native traversal.

Python source acquisition walks every directory component from an opened filesystem-root descriptor using `dir_fd`, directory/no-follow flags and held inode bindings. It reads regular leaves without following or blocking, rechecks ancestors around capture and final witness checks, and closes held descriptors on all paths. Safe unchanged source retains its existing byte/CID identity; new ancestor witnesses are ephemeral fields excluded from serialized snapshots and IR identities. Unsafe source ancestors become uncaptured opaque boundaries; external-ignore ancestors cause strict refusal. Parent traversal in ignore selectors is rejected before lexical normalization, and missing parents retain absence witnesses rather than silently following symlinks.

Cleanup failures propagate as lifecycle failures, not ordinary opaque input. An exited Git context cannot execute another configuration query. These fixes apply to selected shared policy/live/dirty helpers; filesystem/unborn enumeration and metadata opens remain separate paths. Opaque inventory still does not authenticate physical currentness.

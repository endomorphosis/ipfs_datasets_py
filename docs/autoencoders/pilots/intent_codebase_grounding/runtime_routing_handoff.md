# Explicit cached-input runtime routing

The new opt-in `checkpoint_hub.open_ir_cell_autoencoder` connects exact IR-cell inventory selection to the existing fixed local 384D package loader. Existing Hub functions, defaults, domains and the original 12,516-byte Hub source prefix are preserved. The adapter supports experimental cached `source_to_native_ir` replay for LegalIR, SecurityIR and IntentIR at input width 384; it does not infer capabilities for 8D latent models, 768D donors or CodebaseIR envelopes.

## What changed

`ir_cell_runtime.prepare_ir_cell_runtime` accepts the original directory pin, twelve inventory pins, the existing five-field request, an explicit package-manifest pin, one declared cached split and 1–64 ordered unique row IDs. It re-resolves the inventory, validates the fixed package runtime/domain/embedding manifest and every package file, and requires the package checkpoint to equal the selected original path, bytes and SHA256. A copied file with the same digest cannot silently replace that declared path. No published default or Hugging Face download is consulted.

The complete cached split must have its original closed rows envelope. Every row is checked for source UTF-8 SHA256, exactly 384 finite numerical embedding values and their canonical JSON digest, unique ID, declared split and bounded fields. Group, wording and token-ID hash records are retained as metadata; a token hash does not authenticate original encoder execution or token/span qualification. Target dictionaries remain in the existing corpus, and selected decoder inputs contain exactly `id`, `source_text`, `embedding`—no gold targets, groups, wording-style features or token metadata are forwarded.

Opening captures validated primitive options, prepares the binding, then invokes only the existing local `_instantiate` dispatch. The wrapper rechecks all bindings after loading and before and after each `infer_cached()` call. It forwards fresh target-free rows and refuses source/artifact drift or runtime input mutation. It exposes no `infer_texts` entrypoint or arbitrary new-input inference; no embeddings are generated. Per-file stable reads and repeated byte equality are observations, not atomic cross-file or continuous source locks.

The manifest declares experimental capability independently of unknown inventory checkpoint/task binding. Unknown qualified span budgets remain unknown and every task/quality/teacher/span/producer/proof/store/release authority flag remains false. This allows bounded experimental replay without crediting it as teacher quality or a release. Raw candidate results are nested under the adapter's false authority record; a nested result is not evidence of proof. The Legal package remains parser-assisted, and its real loader executes a saved numerical inference fixture while opening.

## Validation and original assets

Four real product initializers execute from pinned source, plus actual router-dependency and test initializers; no synthetic project ancestor modules are injected. The 452 external Python source pins are preserved. Fourteen unrelated Hub cases requiring broader or numerical integrations are explicitly deselected, not counted as passes.

New tests patch only `_instantiate` with an inert loader. Their loader/inference markers simulate calls and qualify dispatch ordering, input isolation and refusal boundaries only. Actual numerical model loads, inference, training, embedding generation, databases, solver/supervisor operations and guarded subprocess/network effects are zero. Full numerical, transitive and native shared-library closure remain pending.

The original-data preparation made 25 requests: three explicit published 384D packages prepared, 22 others refused before loading. It authenticated the original LegalIR, SecurityIR and IntentIR package manifests against the retained published descriptor source and prepared one existing validation row per family with original source/vector digests. All original cached rows in those selected splits are validated; exposure is still unknown, so these are development/replay inputs, not independent teacher evaluation. The current checkout's LegalIR default descriptor differs from the retained inventory's original release. The adapter binds the retained explicit package instead of substituting the current default. The three package manifests are newly acquired pinned metadata, not previously sealed original asset entries. Their hashes match the authenticated original descriptor source.

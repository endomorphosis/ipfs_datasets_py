Git status alone no longer establishes current regular-file bytes. Committed clean snapshots verify bounded physical UTF-8 source bytes against their Git blobs, retaining clean identities when they agree and using working captures when they differ. Descriptor/path witnesses detect replacement during reads; final witnesses reject hidden edits after acquisition. Neither Git index flags nor HEAD equality can make the tested hidden edits appear current.

The catalog now validates separate cancellation and publication callbacks, preserving falsey callable objects. Three publication callbacks run inside the actual DuckDB transaction: before AST mutation, before head/operation writes, and after those writes before commit. The index passes a fresh repository snapshot comparison at each boundary. Source changes, cancellation or callback errors roll back AST, invalidation, head and operation rows together. Exact catalog replay bypasses both callbacks. Snapshots remain point-in-time observations; the planner must reobserve before effects.

The SQL-only run passed **56 cases**, with eight new regressions, zero failures/skips and zero unexpected import/effect denials. Two fresh-child-Python cases were explicitly excluded. It uses pinned DuckDB 1.5.5 Python wrappers and its native module, pinned Git, 38 project-source files, 450 external Python files and two CID data tables. All 57 explicitly opened native connections closed, and Python completion showed only MainThread. Git targets, SQL/CAS data, scheduler state and spill files were private. External access and extension installation/loading were disabled. DuckDB's optional dataframe probes received declared absence for pandas/numpy/pyarrow; no dataframe interoperability was qualified. Native shared-library closure and native-thread absence were not attested. Outer execution had a 180-second deadline plus a five-second forced-kill allowance; DuckDB's 64MB setting bounds engine memory, not the entire process.

The initial precollection refusal and the first 54-pass/two-failure run remain saved. The refusal came from an inherited beartype expectation.

# Country catalog

Indexable `endomorphosis/ipfs_<country>_laws` corpora are packaged as
`justicedao/ipfs_<country>_laws_ir`.

## Excluded from indexing

These source datasets exist but are **incomplete Wayback harvests** and are
not packaged:

| Source | Reason |
| --- | --- |
| `endomorphosis/ipfs_belgium_laws` | incomplete Wayback harvest (Justel / Moniteur belge archive shard) |
| `endomorphosis/ipfs_portugal_laws` | incomplete Wayback harvest (Diário da República archive shard) |
| `endomorphosis/ipfs_lithuania_laws` | incomplete Wayback harvest (e-TAR archive shard) |

Out of scope: `endomorphosis/american_municipal_law`.

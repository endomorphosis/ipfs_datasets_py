# Retained source/span target eligibility census

`legal_source_span_target_eligibility_v1` inventories every physical row and
formal-output occurrence in an independently pinned source/span/entity join.
It replays candidate custody and uses the existing `source_span_formula_v1`
audit to measure decoder expressibility. It does not select a statutory
interpretation, authorize a consumer, load a checkpoint or run training.

## Inputs and API

Use the complete raw UTF-8 join report and a closed JSON request containing:

```json
{
  "schema": "legal-source-span-target-eligibility-request/v1",
  "join_manifest_raw_sha256": "<SHA256 of exact saved report bytes>",
  "join_manifest_sha256": "<join owner's canonical SHA256>",
  "expected_physical_ids": ["<each selected physical identity in original order>"],
  "decoder_profile": "source_span_formula_v1",
  "latent_dimension": 0
}
```

The independent request hash must be supplied separately. Dimension 384 is
also a declared decoder profile, but the existing consumer binding requires
zero latent dimensions; no latent vectors are generated by this census.

```python
from ipfs_datasets_py.logic.autoformal.legal_source_span_target_eligibility_v1 import (
    prepare_source_span_target_eligibility,
    source_span_target_eligibility_sha256,
    validate_source_span_target_eligibility,
)

report = prepare_source_span_target_eligibility(
    request_raw, join_raw, expected_request_sha256=request_sha256,
)
report_sha256 = source_span_target_eligibility_sha256(report)
validate_source_span_target_eligibility(
    report, request_raw, join_raw,
    expected_request_sha256=request_sha256,
    expected_report_sha256=report_sha256,
)
```

Validation regenerates the complete census from the original retained inputs;
resealing a modified report is insufficient. The execution owner must separately
replay the original join against its complete source, table, receipt and metadata
inputs. The census explicitly records that its own selection scope is the pinned
retained join report, rather than claiming fresh upstream acquisition.

## Preserved populations and dispositions

The report retains ordered physical identities, all row references and every
output from the adapter's three producer routes. Shared references do not create
additional physical examples. Missing collections, empty collections, no-output
rows, unsupported formats and decoder refusals remain visible in the denominator.
Duplicate exact source texts are grouped and flagged for consumer compatibility.

Only the explicitly supported typed-deontic family and rule format enter a
canonical wrapper. Their exact payload is wrapped as one rule and sent unchanged
to the existing source-copy audit; original payload bytes, route, ordinal,
producer origin and conditioning flags remain in the output. Unsupported
representations are not rewritten into apparent supported targets. The audit
does not repair compiler choices or establish correspondence with legal meaning.

The current decoder requires one canonical rule, bounded source tokens, exact
unique source-copy atoms, one atom per qualifier and nonoverlapping spans. An
accepted audit establishes representability under those constraints. Runtime
metadata discovery establishes neither checkpoint compatibility nor model
quality; checkpoint assessment is recorded as unperformed.

## Eligibility and integration

All meaning, source, context, field, training and evaluation masks remain zero.
Source occurrence, meaning-unit boundaries, context, applicability, definitions,
review, exposure and split decisions remain unresolved. All authority flags are
false, including semantic verification, model/training execution, proof and Lean
admission. Compatibility blockers preserve unsupported target origins; historical
compiler or guided outputs are not relabeled as weak model supervision.

Feed a later reviewed manifest into the existing source-span consumer binding
only after independently qualifying its complete source/target population,
eligibility, exposure and split declarations. This census supplies coverage and
repair queues; it supplies no authorization to bypass those owners.

Production operations should freeze the actual source closure and retained input
identities, use the workspace logic-tree guard, and hold the existing source read
lease throughout the owned validation child lifetime. The qualification packet
for the selected historical population is maintained outside the repository at
`artifacts/legal-ir-target-eligibility-20261016-01/` in the enclosing workspace.
